## Demo Mode

The demo mode runs automatically if there is no user input.

- Activates after **10 seconds of inactivity** in the Main Menu  
- Plays a randomly selected video as a Demo Mode:
  - **Success Path**  
  - **Failure Path**  
- Stops when any user input is detected
